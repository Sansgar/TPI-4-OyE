
# Organizacion y Empresas - TPI Progresivo Entrega N°4

Entrega final del Trabajo Integrador de la materia Organizacion y Empresas de laTecnicatura Universitaria en Programación a Distancia (TUPaD) de la Universidad Tecnológica Nacional (UTN). 

Este repositorio contiene la documentacion del proyecto, un sistema para ayudar para el diseño, testeo y luego implementacion/comecializacion online de juegos de mesa.

## Declaracion de Uso de IA

- Entrega N°1: se uso Gemini IA para ayudar con el formato de presentacion de las consignas. Y para el diagrama se uso mermaid que tambien tiene soporte IA. Se hizo el diseño original basado en datos le proporcione y después se modifico manualmente. 

- Entrega N°2: se uso Gemini IA para ayudar con el formato de presentación de las consignas. Se idearon equipos y se pidio feedback para reforzarlo. Tambien se uso para tener una idea de los tiempos estimados de cada tarea para el Diagrama de Gantt.

- Entrega N°3: Se desarrollo idea inicial de Organigrama y Diccionario de Datos y después se uso Gemini IA para obtener feedback y ayudar con el formato de la presentacion.

- Entrega N°4: Se uso mas que nada para los Mecanismos de Control para obtener feedback y ayudar con el formato del texto.
